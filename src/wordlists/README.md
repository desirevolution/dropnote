# Passphrase word lists

- `en.txt` contains the [EFF Large Wordlist](https://www.eff.org/files/2016/07/18/eff_large_wordlist.txt) by the Electronic Frontier Foundation, under [CC BY 3.0 US](https://creativecommons.org/licenses/by/3.0/us/). The dice indices were removed.
- `de.txt` contains the [dys2p German Diceware word list](https://github.com/dys2p/wordlists-de), under CC0 1.0. See [DE-LICENSE.txt](DE-LICENSE.txt) for the upstream terms.

Dropnote selects six words independently in the browser. The server only supplies the list.
