# Dropnote glossary

A self-hosted sharing tool: persistent, bidirectionally editable Pads that combine a text Note with Attachments, optionally end-to-end encrypted.

## Language

### The artifact

**Space** (internally, **Pad**)

A shared note and its files at one address. Additional spaces can have an expiry.
_Avoid_: Share (use for the event, not the artifact), paste, board, notepad

**Note**:
The text content of a Pad.
_Avoid_: body, text, description

**Attachment**:
A file attached to a Pad's flat list. The contents and metadata of Attachments on Encrypted Pads are encrypted.
_Avoid_: upload, file, blob

**Default** (internally, **Default Pad**)

The permanent, unencrypted workspace at `/default`. Anyone with instance access can edit it.
_Avoid_: home pad, main pad

### Access

**Share**:
The act of giving someone a Pad's link.
_Avoid_: using "Share" as the name of the artifact (that is the Pad)

**Slug**:
The unique, human-readable address of a Pad, used in its URL — generated by default, optionally custom. Access follows the instance policy and, in multiuser mode, the space permissions. The optional editing PIN gates writes.
_Avoid_: code, id, pad name

**Share Link**:
The direct address of a Pad. An Encrypted Pad also requires its Passphrase.
_Avoid_: share URL, permalink, deep link

**Key**:
The encryption secret derived in the browser from the Pad's Passphrase. The browser can optionally remember it.
_Avoid_: password, secret

**Passphrase**:
The user-supplied secret required to open an Encrypted Pad. It is fixed when the Pad is created.

**PIN**:
A per-Pad numeric credential that unlocks writes for an account with edit permission, including early deletion or expiry changes when the account can manage the Pad.
_Avoid_: password, passcode

**Reader**:
Someone who can open the Pad and read its Note and Attachments.
_Avoid_: viewer, guest

**Editor**:
A Reader who can edit the Note and manage Attachments. When a PIN is set, an Editor must know it.

**Owner**:

The account that created a space in multiuser mode. The owner manages its access grants, expiry and deletion.

### Encryption

**Encrypted Pad**:
A Pad whose Note and Attachments exist on the server only as ciphertext.
_Avoid_: secure pad, E2E pad

**Plain Pad**:
A Pad the server stores unencrypted; readable without the Key.
_Avoid_: unencrypted pad, public pad

**Zero-Knowledge**:
The property that the server stores and relays Encrypted Pad contents as ciphertext. The browser holds the Key.
_Avoid_: server-side encryption

### Lifecycle & behavior

**Start page**

The space this browser opens at the site root. **Default** remains available at `/default`.

**Saved spaces**

The browser-local list of bookmarks. In single-user mode it also shows spaces created in that browser.

**My spaces**

The list of spaces owned by the signed-in account in multiuser mode.

**TTL**:
How long a Pad lives; when it ends, the Pad and its Attachments are deleted. Chosen per Pad at creation, bounded by server configuration.
_Avoid_: expiry, retention

**Live-Sync**:
Real-time propagation of Pad edits between open browsers, with concurrent edits merged automatically.
_Avoid_: realtime editing, collaboration mode
